## 📖 Sobre o repositório

Este repositório reúne as atividades e os projetos desenvolvidos na disciplina de **Desenvolvimento Web**, ministrada pelo professor **Fábio**. Os trabalhos registram a evolução dos estudos, desde a construção de páginas estáticas até o desenvolvimento de funcionalidades com PHP e banco de dados.

## 🚀 Conteúdos aplicados

- Estruturação de páginas com **HTML**;
- Estilização e criação de layouts com **CSS**;
- Lógica e interatividade com **JavaScript**;
- Desenvolvimento de páginas dinâmicas com **PHP**;
- Formulários, cadastro e autenticação de usuários;
- Manipulação de arquivos;
- Integração com banco de dados;
- Uso de imagens, áudios, GIFs e iframes.

## 📂 Projetos e atividades

O repositório contém listas de exercícios de JavaScript e PHP, sites temáticos, páginas com iframes, portais de conteúdo e uma aplicação com cadastro, login e banco de dados.
